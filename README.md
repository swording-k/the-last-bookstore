## 关于

7 天。24 本书。6 个灵魂。1 间还在营业的书店。

你扮演橡木镇唯一还在营业的书店老板。每天门铃会响，会有带着故事的人走进来 — 疲惫的母亲、孤独的老农、自卑的小孩、超负荷的医生、迷惘的女诗人、神秘的旅人。你要做的不只是卖书，而是**听懂他们**，**推荐对的那一本**。

每一次对话、每一次选择都会影响 **希望值（hope）** 和 **声誉（rep）**。7 天后，4 种结局之一等着你。

## 怎么玩

1. 点 **推开那扇门** 开始
2. 每天开场看一段**叙事过场**（大断联背景介绍 + 当日目标）
3. 门铃响 → **接待** → 看 NPC 故事 → **选回应**（三个分支按钮）
4. 想聊点不一样的？点 **💬 和 TA 自由交谈**，AI 真 NPC 实时对话
5. 选完后 **推荐一本书** → 在 24 本书里选 → 看匹配度（完美 / 良好 / 中性）
6. 一本书完成 → 继续接待下一个
7. 一天结束 → **看店主日记**（AI 生成）→ 推进到下一天
8. 第 7 天结束 → 触发结局
9. 随时点右上角 **📚** 打开 **我的书店** → 查看当前推荐记录、待读清单和一个月后的回信
10. 随时点右上角 **📖** 打开 **自由书库** → 不等 NPC，直接查看书、AI 导读，或进入《福尔摩斯探案集》的书中剧场

## 4 种结局

| 结局 | 条件 | 感觉 |
| --- | --- | --- |
| **平凡日子** | 7 天后希望值 40-60 | 你只是个守店的 |
| **守望者** | 7 天后希望值 60-80 | 你让几个人不再孤单 |
| **点燃希望** ✦ TRUE | 第 6+ 天 + hope≥80 + 见过旅人 | 整个小镇都变了 |
| **最后的读者** 🌙 HIDDEN | 第 7 天 + hope≥60 + 见过旅人 + 5+ 完美 | 旅人留下的旧书，笔迹是祖父的 |

## AI 用了哪里？

- **6 张 NPC 立绘**（matrix AI 出图，3 轮 prompt 迭代）
- **24 张书封面**（同上）
- **4 段 BGM / 4 个 SFX**（matrix AI 音乐生成）
- **NPC 自由对话**（阿里云百炼 qwen-plus 流式，6 秒内生成含剧情细节的角色扮演回复）
- **书籍 AI 导读**（同上，问作者问题、聊书背后故事）
- **每日店主日记**（模板 + LLM 润色）
- **结果世界风注释**（完美/良好/中性匹配各一套氛围文案）
- **一个月后回信**（推荐记录生成后续回信，LLM 不可用时走本地 fallback）

## 新版本亮点：我的书店

结局不再只是结束。玩家可以打开 **我的书店**，看到自己七天里推荐过哪些书、把哪些书加入了“我想读”的待读清单，并复制书名去微信读书、图书馆或线下书店搜索。

这让《最后的书店》从剧情游戏变成真实阅读入口：游戏不是终点，它只是把玩家带回真实阅读的入口。

现场演示时不必玩到结局。打开 `/?demo=1` 后，顶部工具条可以一键跳到结局或打开「我的书店」；正常游戏中也可以随时点右上角 📚 查看当前进度。

## 新版本亮点：自由书库与书中剧场

玩家不必等到 NPC 推荐环节，也可以随时点右上角 **📖** 打开自由书库。自由浏览模式下，书籍详情页不会出现“推荐这本书”的任务按钮，只保留阅读相关互动：书籍简介、AI 导读，以及带有 `bookWorld` 的沉浸式入口。

当前自由书库会把带有沉浸式剧场的书置顶，并显示 **沉浸式剧场推荐**。第一批演示书有两本：

- 《福尔摩斯探案集》：进入贝克街 221B，与夏洛克·福尔摩斯、华生医生、雷斯垂德探长进行卡片式或自由提问式对话。
- 《小王子》：进入 B612 星球，与小王子、狐狸、玫瑰聊孤独、爱、责任和“真正重要的东西”。

没有 API Key 时也有角色化 fallback，有 Key 时会走真实 LLM。

## 演示真实 LLM

本仓库不提交 API Key。没有 Key 时，NPC 对话、书籍导读和一个月后回信都会走本地 fallback，断网也能展示。

需要现场演示真实流式 LLM 时，可以在浏览器控制台临时设置：

```js
localStorage.setItem('tlb_llm_api_key', '你的临时演示 Key')
```

也可以复制 `demo-key.local.example.js` 为 `demo-key.local.js`，把临时 Key 填进去。本文件已被 `.gitignore` 忽略，只用于本机演示。

更稳妥的线上做法是把 Key 放在服务端或部署平台环境变量里，再由服务端代理请求。
