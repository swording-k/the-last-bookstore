# 最后的书店 / The Last Bookstore

> 腾讯云 AI 黑客松 40 赛道 · 叙事剧情游戏
> 你能不能在第 7 天之前，点燃这个小镇最后一点希望？

## 30 秒上手

```bash
cd the-last-bookstore
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

## 关于

大断联后的第 7 年，云端知识沉默，纸质书重新成了人类能握在手里的记忆。

7 天。24 本书。6 个灵魂。1 间还在营业的书店。

你扮演橡木镇唯一还在营业的书店老板。每天门铃会响，会有带着故事的人走进来——疲惫的母亲、孤独的老农、自卑的小孩、超负荷的医生、迷惘的女诗人、神秘的旅人。你要做的不只是卖书，而是**听懂他们**，**推荐对的那一本**。

每一次对话、每一次选择都会影响 **希望值（hope）** 和 **声誉（rep）**。7 天后，4 种结局之一等着你。

## 怎么玩

1. 点 **推开那扇门** 开始
2. 门铃响 → **接待** → 看 NPC 故事
3. 在对话中**选回应**（也可自由输入，AI 解析情绪）
4. 选完后 **推荐一本书** → 看匹配度
5. 一本书完成 → 继续接待下一个
6. 一天结束 → **看店主日记**（AI 生成）→ 推进到下一天
7. 第 7 天结束 → 触发结局

## 4 种结局

- **平凡日子**（基础）—— 你只是一个普通的店主
- **守望者**（good）—— 你让一些人不再孤单
- **点燃希望**（true）—— 整个小镇都变了
- **最后的读者**（hidden）—— 旅人留下的旧书，笔迹是祖父的

## AI 用了哪里？

- **6 张 NPC 立绘**（matrix AI 出图，3 轮 prompt 迭代）
- **24 张书封面**（同上）
- **4 段 BGM / 4 个 SFX**（matrix AI 音乐生成）
- **自由输入情绪识别**（本地 NLP + 可选 LLM）
- **作者灵魂对话**（书籍内置 + 可选 LLM）
- **每日店主日记**（模板 + 可选 LLM）

## 部署建议

赛事提交需要一个浏览器可访问的在线链接。GitHub Pages 链接如果已经能稳定打开，就可以作为主提交链接。

本项目也保留了 `vercel.json`，可一键导入 Vercel 做备用镜像。Vercel 不是必需项，但建议作为评审打不开 GitHub Pages 时的第二入口。

如需演示真实流式 LLM，不要把 API Key 提交到仓库；可在浏览器控制台临时设置：

```js
localStorage.setItem('tlb_llm_api_key', '你的临时演示 Key')
```

工程文档：[docs/DEV.md](docs/DEV.md)
