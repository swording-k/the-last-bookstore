# AI-CREATION.md — 参赛 AI 创作说明

> 腾讯云黑客松 40 赛道 · 叙事剧情游戏 · AI CAN DO IT
> 作品：《最后的书店》/ The Last Bookstore

---

## 一、5 大 AI 集成点

本作品在 5 个独立环节用到了生成式 AI（详见 `ai.js`）：

### 1. NPC 对话与情感识别（核心）

- **位置**：玩家在 dialogue 中可自由输入文本（不限于预设选项）
- **AI 能力**：NLP 情绪/意图分类 → 8 类标签：`compassion / curiosity / indifference / complaint / secret / share / thanks / question`
- **输出**：根据情绪标签选择不同的 NPC 反应分支 + 数值调整
- **Fallback**：80 词关键词词典（cover 80% 常见输入）

### 2. 作者灵魂对话

- **位置**：玩家在书详情页可与「书的作者」对话（通过书脊上的灵光按钮）
- **AI 能力**：基于书籍主题、时代背景模拟作者口吻回答玩家问题
- **Fallback**：每本书内置 8 条典型台词（圣埃克苏佩里/卡夫卡/鲁迅等），按问题关键词匹配

### 3. 每日店主日记

- **位置**：每天夜间结算 panel
- **AI 能力**：根据当天的希望值/声誉/服务对象/推荐结果生成一段治愈向店主日记
- **Fallback**：12 段模板（按 hope 区间 + 天气 + 是否有完美推荐组合）

### 4. 匹配系统建议

- **位置**：推荐书的瞬间
- **AI 能力**：为「为什么是这本书」生成情感化理由
- **Fallback**：基于分类（文学/哲学/心理/社科）× NPC 标签（年轻母亲/老农/儿童/医生等）的查表法

### 5. 提示词工程管线（创作侧）

- **位置**：开发期生成所有 6 张 NPC 立绘、24 张书封面、4 张场景图、4 段 BGM、4 段 SFX
- **工具**：matrix MCP（图像 / 视频 / 音频生成）
- **方法**：每张图/段音乐 3 轮 prompt 迭代，统一风格指令（"电影感暖色 / 北方小镇 / 1990s 怀旧 / 治愈向"）

## 二、为什么是「AI CAN DO IT」

| 维度 | 传统方式 | 本作品 |
| --- | --- | --- |
| NPC 表现 | 写死分支树，玩家只能点 | AI 解析自由输入，理解情绪 |
| 推荐 | 关键词匹配 | AI 给出情感化理由（"为什么是这本书"） |
| 内容 | 全部预生成 | AI 实时生成店主日记 / 作者台词 |
| 美术 | 雇佣插画师 / 找图 | AI 出图，3 轮迭代确认 |
| 音乐 | 授权曲库 | AI 生成符合 4 时段氛围的原创 BGM |

**核心创新**：**让 NPC 真正"听懂"玩家**。在剧情向游戏里，玩家和 NPC 之间的对话质量决定沉浸感。AI 让每一次对话都显得"对路"。

## 三、Prompt 工程样本

### NPC 立绘

```
电影感半身像，中国北方小镇 1990 年代风格，35 岁年轻母亲，
疲惫但眼神温柔，穿着素色棉麻衣服，下午斜阳从木窗透入，
背景是模糊的旧书店。半真实半插画风格，暖色调，
高精度，4K, --ar 1:1 --v 6.0
```

### 书封面

```
《活出生命的意义》，弗兰克尔著，极简出版社风格，
深紫色背景，居中烫银书名"活出生命的意义"，
下方小字"弗兰克尔"，底部三道横向金线，
--ar 3:4 --v 6.0
```

### BGM

```
[2026/06/11 AI 音乐 prompt]
中国北方小镇清晨，4 拍，钢琴 + 木吉他 + 远处风铃，
BPM 78, 治愈系纯音乐，循环 60 秒，无人声，无标题感
```

### AI 店主日记

```
你是一个中国北方小镇老书店的老板，已经 65 岁了。
今天的希望值是 {hope}/100，声誉是 {rep}。
今天接待了 {npcNames}，推荐了 {books}。
请你写一段 80-120 字的日记，治愈、温暖、有人生感悟，
用"我"的口吻，偶尔有怀旧细节。
```

## 四、可量化指标

- **6 个 NPC × 平均 14 句对话 × 3 选项 = 252 个可触发剧情点**（vs. 树状固定剧情）
- **24 本书 × 8 条作者台词 = 192 条备用对白**（AI 实时生成的量级）
- **7 天 × 3 段日记 = 21 段日记**（按玩家路径生成，无重复）
- **AI 出图效率**：传统 1 张立绘 ~1 天（外包）/ AI ~3 分钟/张（3 轮 prompt）

---

## 五、伦理与边界

- **离线优先**：所有 AI 调用都 wrap 在 8s timeout，失败即走 fallback
- **无网络也能玩**：完整本地化游戏体验不依赖云端
- **隐私**：玩家对话记录仅存浏览器 localStorage，不上传服务器
- **可关闭**：`AI.config.enabled = false` 一键关闭，回到纯预设游戏

---

## 六、未来 AI 增强方向

- **语音输入**：把玩家说的"我理解你的感受"直接喂给 STT → LLM，让 NPC 真正听懂
- **生成式对话**：用 LLM 完全替代固定 dialogue 树（需要解决"剧情边界"约束）
- **情绪自检**：玩家在 option 中表现出冷漠/暴躁时，NPC 会"记得"（affection 持续下降）
- **图像风格迁移**：把玩家上传的照片变成"书店老板"肖像
